# The live preview

- Open any `.tex` file and click the **preview icon** in the editor's title bar, or press **Ctrl+Alt+V** (**Cmd+Alt+V**).
- The main file is found automatically: a `% !TEX root = main.tex` line, the file with `\documentclass`, or the file that `\input`s the one you are editing.
- As you type, the paragraph you edit is re-typeset in about a millisecond. Page breaks, references and the rest follow from a full compile a moment later.
- The pill in the preview's toolbar says what is happening: **Live**, **Updating layout…**, **Up to date** or **errors**. Hover it for details.
