# What Realtime TeX needs

| | |
|---|---|
| **Operating system** | Linux, macOS or Windows. |
| **LuaLaTeX** | TeX Live 2026 or newer. The setup check can install a minimal TeX Live for you. |
| **rtex** | The engine from [realtime-tex](https://github.com/HenryXiaoYang/realtime-tex). One click builds it (needs [Rust](https://rustup.rs); on Windows also [Git for Windows](https://git-scm.com/download/win) and the Visual Studio C++ Build Tools). |

**Check Setup** tests each item and offers a fix for anything that is missing.
