# What Realtime TeX needs

| | |
|---|---|
| **Operating system** | Linux or macOS. On Windows, use [WSL](https://code.visualstudio.com/docs/remote/wsl). |
| **LuaLaTeX** | TeX Live 2026 or newer. The setup check can install a minimal TeX Live for you. |
| **rtex** | The engine from [realtime-tex](https://github.com/HenryXiaoYang/realtime-tex). One click builds it (needs [Rust](https://rustup.rs)). |

**Check Setup** tests each item and offers a fix for anything that is missing.
