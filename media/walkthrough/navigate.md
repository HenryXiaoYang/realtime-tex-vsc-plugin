# Source ↔ preview

| Action | Result |
|---|---|
| Move the cursor in the editor | The preview scrolls to that paragraph (turn this off with **Follow cursor**). |
| **Ctrl+Alt+J** | Jump the preview to the cursor and highlight the spot. |
| **Double-click** (or Ctrl/Cmd+click) in the preview | Jump to that paragraph in the source. |
| **Ctrl + mouse wheel**, **Ctrl + = / −** | Zoom the preview. **Fit width** fits the page to the panel. |
